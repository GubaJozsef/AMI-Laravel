# AMI-Laravel

AMI-Laravel is a learning-focused project created to explore and understand the Laravel framework.  
The project was developed independently alongside my university studies, driven by my interest in modern web development technologies.

## Project Purpose

The main goal of this project was to:
- Learn the fundamentals of the Laravel framework
- Understand MVC architecture in practice
- Work with backend logic, routing, and database interactions
- Gain hands-on experience with PHP-based web applications

## Technologies Used

- PHP
- Laravel Framework
- Blade templating engine
- MySQL (or relational database concepts)
- HTML / CSS
- Local development environment (e.g. XAMPP, Laravel Artisan)

## Key Concepts Practiced

- MVC (Model–View–Controller) architecture
- Routing and controllers
- Database models and migrations
- Basic CRUD operations
- Server-side rendering with Blade templates

## Learning Outcomes

Through this project, I:
- Gained a solid understanding of Laravel basics
- Learned how modern backend frameworks structure applications
- Improved my ability to learn new technologies independently
- Strengthened my web development and backend thinking

## Notes

This project was created as a self-learning exercise and is intended to demonstrate my ability to independently explore new frameworks and technologies.  
It may be extended in the future as my experience with Laravel grows.
